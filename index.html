🥋 SISTEMA DE COMBATE CUERPO A CUERPO
  • Combo de 4 golpes: Presiona repetidamente Golpe para encadenar Jab → Cross → Patada → Golpe Final.
  • Knockback: El último golpe lanza al rival contra el límite del escenario con daño aumentado.
  • Guardia / Bloqueo: Mantener Defensa reduce un 75% del daño y evita ser empujado.
⚡ SISTEMA DE ENERGÍA Y KI
  • Cargar Ki: Mantén presionado Carga de Ki para regenerar tu medidor azul con aura.
  • Ráfagas Ki: Ataques de proyectil rápidos a distancia (consumen 6 Ki).
  • Super Rayos (Kamehameha, etc.): Requieren 35 Ki. Atraviesan proyectiles normales y causan daño continuo.
  • Choque de Poderes (Beam Clash): Si dos rayos chocan de frente, ¡pulsa botones rápidamente para ganar el choque!
🎮 COMPATIBILIDAD CON MANDOS
  • Conecta cualquier mando de Xbox, PlayStation o genérico USB y se detectará automáticamente.
  • Stick/D-pad para moverte, X para golpear, A para Ki, B para Rayo, Gatillos para Cargar y Dash.
